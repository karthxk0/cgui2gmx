# cgui2gmx v1.3

A streamlined Python tool designed to automate and simplify running MD simulations in GROMACS using inputs generated by CHARMM-GUI. 

Instead of manually typing out a dozen `grompp` and `mdrun` commands and manually extracting energy data, `cgui2gmx` handles the entire sequence for you. It intelligently reads your CHARMM-GUI directory, figures out the required steps, runs the simulations, and even plots the equilibration metrics (Temperature, Pressure, Density, Potential Energy) automatically.

---

## About

In a typical MD workflow, after downloading the CHARMM-GUI archive, you have to run a minimization step, followed by several equilibration steps (often up to 6), and finally a production run. For each of these, you must run `gmx grompp` and `gmx mdrun`. Instead of manually typing out a dozen `grompp` and `mdrun` commands and manually extracting energy data, `cgui2gmx` handles the entire sequence for you. It intelligently reads your CHARMM-GUI directory, figures out the required steps, runs the simulations, and even plots the equilibration metrics (Temperature, Pressure, Density, Potential Energy) automatically.

**What `cgui2gmx` does for you:**
1. **Dynamic File Discovery:** It automatically finds your `_input.gro`, `_minimization.mdp`, `_equilibration.mdp`, and `_production.mdp` files. It understands how many equilibration steps you have and orders them correctly.
2. **Automated Command Execution:** It builds and executes the `grompp` and `mdrun` commands for every single step consecutively.
3. **Smart `maxwarn` Handling:** It reads the CHARMM-GUI README to detect if a `-maxwarn` flag is needed for the minimization step and applies it automatically so your run doesn't crash on known CHARMM-GUI warnings.
4. **MPI & GPU Support:** It asks if you want to use `gmx_mpi` and GPU acceleration, adjusting the commands (`-nb gpu`) accordingly.
5. **Post-Run Auditing & Plotting:** After each step completes, it silently runs `gmx energy` to extract relevant thermodynamic data (Potential Energy for minimization; Temperature, Pressure, and Density for equilibration). If `matplotlib` is installed, it instantly generates beautiful `.png` graphs so you can verify your system is equilibrated before the production run finishes.

## Prerequisites & Installation

### Prerequisites
*   **GROMACS:** Must be installed and accessible in your system PATH (either `gmx` or `gmx_mpi`).
*   **Python 3.x:** Required to run the script.
*   **Python Packages:**
    *   `colorama` (Optional, but recommended for colored terminal outputs)
    *   `matplotlib` (Optional, but **highly recommended** to automatically generate `.png` plots of your energy terms)

### Installation
1. Clone this repository or download the `cgui2gmx.py` script to your local machine.
2. Make the script executable:
   ```bash
   chmod +x cgui2gmx.py
   ```
3. Install the recommended Python packages:
   ```bash
   pip install colorama matplotlib
   ```

## Usage Tutorial

Here is how you use `cgui2gmx` in a real-world scenario, from downloading your files to analyzing the plots.

### Step 1: Download & Extract CHARMM-GUI Output
Once your system is built on the CHARMM-GUI website, download the `.tgz` archive.
Extract it in your terminal:
```bash
tar -zxvf charmm-gui-step*.tgz
```
This will create a `charmm-gui` folder containing several subfolders. We are interested in the `gromacs` subfolder.

### Step 2: Update Your `.mdp` Parameters (Crucial Step!)
Before running *any* simulations, you need to set your simulation parameters. CHARMM-GUI provides defaults, but you must adjust them for your specific research needs.
1. Navigate to the extracted folder: `cd charmm-gui-*/gromacs/`
2. Open the `.mdp` files in your text editor (e.g., `nano step5_production.mdp`).
3. Update parameters like `nsteps` (simulation time), `dt` (time step), or temperature settings. 
   *(Note: Remember to do this for both equilibration and production `.mdp` files as needed!)*

### Step 3: Run the Automation Script
Now, execute the `cgui2gmx.py` script. You can run it from anywhere.
```bash
/path/to/cgui2gmx.py
```
The script will prompt you for the path to your CHARMM-GUI extracted folder. You can provide either the main folder or the `gromacs` subfolder directly.
```text
Enter path to CHARMM-GUI extracted folder or its 'gromacs' subfolder: ./charmm-gui-12345/gromacs
```

### Step 4: Answer the Prompts
The script will ask you two simple questions:
1. **Use GPU acceleration?** (Enter `1` for Yes if you have a CUDA-enabled GROMACS build, otherwise `2` for No).
2. **Use MPI?** (Enter `1` for Yes to use `gmx_mpi`, or `2` for No to use standard `gmx`).

### Step 5: Sit Back and Monitor
The script will now take over. It will display a progress bar and start running the Minimization step.
*   Once Minimization finishes, it will extract the potential energy and save a `stepX_minimization_potential.png` plot.
*   It will then loop through all Equilibration steps. As each one finishes, it generates plots for Temperature, Pressure, and Density. 
*   **Pro Tip:** While the script is running the long Production step, you can open the `.png` files generated in the `gromacs` folder to verify that your system successfully equilibrated!

---

## Functioning 

1. **Path Normalization:** Resolves the provided directory path and hunts for the `gromacs` subfolder.
2. **Regex Parsing:** Uses regular expressions to sort equilibration files by step number (e.g., `step4.1`, `step4.2`).
3. **Subprocess Management:** Utilizes Python's `subprocess.Popen` to stream GROMACS output to your console in real-time, catching and highlighting warnings/errors.
4. **Energy Extraction:** Feeds inputs into `gmx energy` programmatically to avoid interactive prompts, outputting `.xvg` files.
5. **Data Visualization:** Parses the raw text of the `.xvg` files (ignoring GROMACS header comments) and uses `matplotlib` to render clean, readable graphs.
